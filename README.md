# Age-of-Silviculture-Uruguay

This is a script adapted from Silva Junior et al. (2020) to calculate the age of areas with silviculture based on the land use classification of the MapBiomas project (https://pampa.mapbiomas.org). Links lead back to the original publication and script on GEE.

Paper:
https://doi.org/10.1038/s41597-020-00600-4

Original Code: https://github.com/celsohlsj/gee_brazil_sv/blob/master/gee_brazil_sv_toolkit_download.js
